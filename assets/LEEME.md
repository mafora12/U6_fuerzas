# Aquí va la música

Pon tu interpretación de *Victor's Piano Solo* en esta carpeta con el nombre **`musica`**:

- `musica.mp3` (recomendado)
- o `musica.m4a`, `musica.wav`, `musica.ogg`

La página la carga sola. En la presentación:

- **Enter**: reproducir / pausar

Si el archivo no está, la página funciona igual y el panel (tecla **H**) muestra el aviso "Falta la música".

> Si tu archivo pesa más de 100 MB, GitHub no lo acepta. Expórtalo como mp3 (≈ 3–8 MB para 3 minutos).
